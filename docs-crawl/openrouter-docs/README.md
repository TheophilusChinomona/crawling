# OpenRouter docs (crawled)

Local mirror of [OpenRouter documentation](https://openrouter.ai/docs).

For a machine-readable index (path + URL for each page), see [index.yaml](index.yaml).

**Models and capabilities:** [models.yaml](models.yaml) and [models.json](models.json) list all OpenRouter models (id, name, context_length, modality, input/output modalities, supported_parameters, pricing). Models are split into **free_models** (prompt and completion both $0) and **paid_models**. Generated from the [OpenRouter models API](https://openrouter.ai/api/v1/models). To refresh, run from repo root: `python crawler/scripts/fetch_openrouter_models.py --output docs-crawl/openrouter-docs/models.yaml`.
